# GitHub Copilot Instruktioner: Svensk språkvård

Lägg till följande avsnitt i din `.github/copilot-instructions.md` i repositoriet för att styra GitHub Copilot:

```markdown
## Svensk språkvård & textgenerering (Humanizer Svenska)

När du skriver eller granskar svensk text i detta arkiv (dokumentation, markdown-filer, texter, kommentarer):
1. **Undvik AI-klyschor:** Använd aldrig inledningar som "I en alltmer digitaliserad värld...", "Det är viktigt att notera att..." eller modeord som "sömlös", "robust" och "banbrytande".
2. **Naturlig meningsbyggnad:** Variera meningslängden kraftigt. Undvik att alla meningar är 15–20 ord långa. Blanda korta satser med längre.
3. **Svensk syntax (Fundamentvariation):** Börja inte varje mening med "Detta..." eller "Systemet...". Variera med tidsuttryck, plats eller bisatser i meningsbörjan.
4. **Inga tankstreck mitt i meningar:** Använd inte em-dashes (—). Använd kommatecken eller punkter.
5. **Konkretion framför fluff:** Ange konkreta siffror och funktioner istället för abstrakta superlativ.
```
